# Units. — student living, redefined

An original, production-ready recreation of the supplied Units reference experience. The site combines a floating desktop-window layout with a responsive mobile experience, animated page transitions, a cursor-reactive perspective tunnel, editorial content cards and an interactive booking flow.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run lint
npm run build
npm start
```

## Deploy to Vercel

Import this repository in Vercel. Framework detection, build command and output settings are automatic; no environment variables are required.

## Stack

- Next.js App Router
- React + TypeScript
- Motion for transitions and micro-interactions
- Lucide icon system
- Local optimized WebP assets

All navigation and booking interactions are keyboard accessible, and reduced-motion preferences are respected.
